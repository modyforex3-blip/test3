# 💎 منصة وتطبيقات مليونير | Millionaire Apps Portal

بوابة إلكترونية متطورة لعرض وتوزيع التطبيقات والأدوات الرقمية لرواد الأعمال والمستثمرين، مصممة بأحدث تقنيات الويب مع دعم متعدد اللغات (عربي / إنجليزي)، لوحة تحكم كاملة للمدير، ونظام إعلاني احترافي متوافق 100% مع معايير **Google AdSense** و **Monetag**.

---

## ✨ المميزات الرئيسية للموقع

1. **تصميم عصري وفخم (Luxury Obsidian & Emerald/Gold):**
   - هوية بصرية مخصصة باسم «مليونير» مع شعار أيقوني متحرك بنظام SVG.
   - بطاقات زجاجية تفاعلية (Glassmorphism) وتأثيرات بصرية راقية وسريعة الاستجابة.

2. **شبكة عرض التطبيقات (Apps Grid):**
   - عرض التطبيقات في شبكة مرنة (يمكن التحكم بعدد أعمدتها: 2، 3، أو 4 أعمدة).
   - بطاقة لكل تطبيق توضح: صورة التطبيق، اسمه بالعربية والإنجليزية، تقييم النجوم، عدد التحميلات، شارة "مميز"، أبرز مميزاته، وزر "عرض التفاصيل".
   - محرك بحث فوري وتصنيف سريع (تداول واستثمار، بلوكتشين، ذكاء اصطناعي، أدوات إنتاجية).

3. **صفحة تفاصيل التطبيق المستقلة (`/app.html?id=...`):**
   - استعراض شامل للتطبيق مع قائمة المميزات الكاملة.
   - رابط التحميل المباشر وزر مشاركة الرابط.
   - مساحات جانبية آمنة للإعلانات وتطبيقات ذات صلة.

4. **لوحة تحكم المدير الشاملة (`/admin`):**
   - كلمة المرور الافتراضية: `admin123millionaire` (قابلة للتغيير من الإعدادات).
   - **إدارة التطبيقات:** إضافة تطبيقات جديدة مع إمكانية رفع صور من الجهاز مباشرة أو عبر رابط URL، تعديل أي تطبيق، وحذفه.
   - **تخصيص العرض:** تغيير اسم الموقع، الشعار، عدد أعمدة الشبكة.
   - **صندوق الرسائل:** استقبال وإدارة رسائل الزوار من صفحة "اتصل بنا".

5. **دعم ثنائي اللغة ذكي (i18n):**
   - يدعم العربية (RTL) والإنجليزية (LTR).
   - يكتشف تلقائياً لغة وموقع الزائر بناءً على المتصفح والمنطقة الزمنية.
   - زر تبديل سريع بين اللغتين مع حفظ تفضيل الزائر.

6. **إعلانات متوافقة مع Google AdSense و Monetag:**
   - **بانر علوي ثابت (Top Banner 728x90):** بمقاس قياسي لا يغطي المحتوى.
   - **بانر سفلي ثابت (Bottom Sticky Banner):** متوافق مع معايير المشاهدة العالية دون مضايقة المستخدم.
   - **إعلانات مدمجة (In-Feed Native Ads):** تندمج بين بطاقات التطبيقات وتظهر كإعلان ممول مميز.
   - إمكانية تفعيل أو تعطيل أي بانر وتغيير أكواد الإعلانات مباشرة من لوحة المدير دون تعديل الكود البرمجي!

7. **الصفحات الإضافية المدمجة:**
   - **اتصل بنا (`/contact`):** نموذج مراسلة متصل مباشرة بقاعدة البيانات ولوحة المدير.
   - **سياسة الخصوصية (`/privacy`):** مصممة بدقة لتلبية شروط Google AdSense وملفات الكوكيز وMonetag وGDPR.

## 🚀 التشغيل المحلي (Local Development)

```bash
# تثبيت الحزم
npm install

# تشغيل الخادم
npm start
```
افتح المتصفح على: `http://localhost:3000`  
لوحة المدير: `http://localhost:3000/admin` (كلمة المرور: `admin123millionaire`)

## 🌐 النشر التلقائي على Render (Render Deployment)

1. توجه إلى [Render.com](https://render.com) وسجل الدخول بحساب GitHub الخاص بك.
2. اضغط على **New +** ثم اختر **Web Service**.
3. اختر مستودعك: `modyforex3-blip/test3`.
4. املأ البيانات كالتالي:
   - **Name:** `millionaire-portal`
   - **Environment:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
5. اضغط على **Create Web Service**.
6. سيقوم موقع Render بنشر الموقع في ثوانٍ وتزويدك برابط مباشر مجاني يعمل 24/7 (مثل: `https://millionaire-portal.onrender.com`).
