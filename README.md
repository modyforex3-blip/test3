# millionair.site PWA Hub

واجهة عربية لإدارة ورفع تطبيقات PWA كملفات ZIP، واستضافتها على نطاق فرعي لكل تطبيق باستخدام خدمة Render واحدة.

## النشر على Render

1. ادفع هذا المستودع إلى GitHub ثم في Render اختر **New → Blueprint** واربط المستودع. سيقرأ Render إعداد `render.yaml`.
2. عند إنشاء الخدمة، أدخل `ADMIN_USERNAME` و`ADMIN_PASSWORD` كقيم سرية قوية. أنشئ كلمة مرور فريدة ولا تشاركها. يقوم Render بإنشاء `SESSION_SECRET` تلقائياً.
3. انتظر اكتمال النشر. افتح نطاق Render المؤقت، ثم أضف في إعدادات الخدمة **Custom Domains** كلا من `millionair.site` و`*.millionair.site`، واتبع قيمة DNS التي يعرضها Render.
4. لدى مزود DNS للدومين، أنشئ سجل wildcard للاسم `*` (عادة CNAME إلى اسم خدمة Render الظاهر في لوحة Render). أضف سجل الدومين الأساسي كما يطلب Render. احذف سجلات AAAA المتعارضة إن وجدت، ثم انتظر انتشار DNS والتحقق وإصدار HTTPS.
5. افتح `https://millionair.site` لإدارة التطبيقات. كل ZIP صالح يحتوي `index.html` في الجذر سيُنشر مثل `https://اسم-التطبيق.millionair.site`.

لا تضع سجل CNAME أو أي قيمة تخمينية من هذا الملف؛ استخدم الوجهة وسجلات DNS التي تظهر في لوحة Render، فقد تختلف حسب الحساب ومزود DNS. يتطلب التخزين الدائم قرص Render المعرّف في `render.yaml`، وهو مرتبط بخطة مدفوعة؛ لا تغيّر الخدمة إلى عدة مثيلات مع قرص محلي مشترك.

## تجهيز تطبيق PWA

صدّر ملفات البناء النهائي (مثل `index.html` وملف manifest وservice worker والأصول) في ZIP مباشرة، بحيث يكون `index.html` في جذر الأرشيف، وليس داخل مجلد إضافي. استخدم لكل تطبيق اسماً فرعياً فريداً من الأحرف الإنجليزية الصغيرة والأرقام والشرطات. جميع مسارات الم��فات في الأرشيف تُفحص لمنع الخروج من مجلد التطبيق، وتُرفض الروابط الرمزية.

## ملاحظات

- صفحة المدير لا تعرض نفسها عبر نطاق فرعي للتطبيق؛ موقع الإدارة على النطاق الأساسي.
- كلمة مرور المدير والإعدادات السرية محفوظة في Environment Variables على Render، بينما ملفات التطبيقات تحفظ على القرص الدائم.
- النسخة الأولى مهيأة لمدير واحد وخدمة واحدة. لا ترفع ملفات غير موثوقة، ولا تشارك بيانات الدخول.
- محلياً: `npm install` ثم اضبط `ADMIN_USERNAME` و`ADMIN_PASSWORD` و`SESSION_SECRET` و`BASE_DOMAIN` و`DATA_DIR` ثم `npm start`.
